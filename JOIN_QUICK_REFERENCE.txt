4. THE BUG (Technical)
   File: executor/join.rs lines 277-292 (combine_rows function)
   
   Problem:
   HashMap::insert() without prefixes overwrites columns with same name
   
   Example:
   Patient table has: {name: "Alice"}
   Admission table has: {name: "Admission-001"}
   Result has: {name: "Admission-001"}  <- Patient name LOST!
